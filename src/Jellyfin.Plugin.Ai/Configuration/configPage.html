Shoal AI

Optional AI help for the other Shoal plugins' hard decisions, within limits you set. Nothing is sent until you allow it.

What may use AI
What is sent

Ingest sends release names, the titles and years it read, and the candidate titles. Subtitles sends short subtitle and transcript excerpts with the title.

Never sent: file paths, user names, or anything from home video and photo libraries. What is sent goes only to the providers you enable below.

Providers and keys
About keys, models and the Test button

Keys are stored on this server in a file only Jellyfin can read. They are never shown again, logged or included in exports; you can replace or clear them.

Leave the model empty to use the recommended model (for Claude, Claude Opus 5.5), updated with plugin releases. Naming a model pins it: it may cost more, and the provider may retire it.

Test sends one tiny request (a fraction of a cent, counted like any other). A prepaid credit is usually bought in US dollars; what's left counts only this plugin's use of the key.

Spending
How limits and currencies work

0 means no paid providers at all. A provider stops at whichever limit it reaches first: the overall limit, its own limit below, or the one you set with the provider.

With "Allow Subtitles to use this budget" ticked (the default), Shoal Subtitles' paid speech-to-text (Deepgram, OpenAI) counts here too and has its own limit below; its keys stay in Subtitles, and only amounts are exchanged. Untick it and Subtitles uses its own currency and limit again.

Providers usually charge in US dollars; charges are converted with the European Central Bank's daily rates, and paid calls pause rather than guess if current rates aren't available.

Limit per provider

An amount, or a share of the overall limit. Local services cost nothing and have no limit. Speech-to-text is listed while Shoal Subtitles is installed.

Taxes and card fees
For GST on overseas services or a foreign-transaction fee, so limits match what you pay. Default 0.
Recent calls
What the log keeps

The time, which plugin asked and why, the model, the outcome, tokens, cost and duration of each call, for the last 1,000 calls or 30 days. Never what was sent (only its size) or the answer's text. Kept on this server in a file only Jellyfin can read.
